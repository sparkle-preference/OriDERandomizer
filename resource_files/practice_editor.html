How this works

Practice Segments: A practice segment is a save file plus some rules: where you start, what the end condition is, what pickups are in the world. PRACTICE MODE on the title screen to enter the segment select menu. Pick a segment to run it, or press Copy (C by default) on it to edit it. Unfinished segments jump straight to the editor. A .bfrp someone gave you only runs until you hold Copy on its card to extract it into a folder.

Editor: The editor freezes the world and opens the Edit Boxes window: Create Box draws a box (item, solid, kill, unsafe or goal), Adjust Boxes moves and resizes them, Delete Boxes deletes the one you click, and Undo takes back the last change. WASD pans the view and right click warps Ori to the mouse and loads nearby scenes. Save saves, Reload reloads from disk, Save & Retry saves and begins a run on the segment, and Open in Browser opens this page. While you are editing, the randomizer's other keybinds are off, and the pause menu is replaced with practice-specific options.

Web Editing Helper: This page allows for advanced configuration of practice segments - QTM compatibility, box options (color, position, visibility, and items), ending conditions more complicated than a box collider, shuffle groups, the briefing, and variants. (For more info on each of these topics, check out the Practice Mode FAQ bug Eiko in the dev discord to get the FAQ written.) When you are finished making changes, click Save to game at the bottom of the page.

The map: Pick locations from the zone and location lists or click them on the map to select locations required to finish the segment or to include in a shuffle group. With edit boxes on the map on, drag a box to move it and its corners to resize it.

Misc Info: A run ends when ALL of its end conditions are satisfied and needs to have at least one. The Retry Practice Segment Randomizer Bind (default Alt+L) restarts an attempt, and dismisses an open briefing if one exists. Quitting to menu ends a practice run unless it is QTM-enabled - ending a QTM-enabled run can be done from the main menu. Segments you make are folders in [Your Ori Install]\practice. To share one, send its export\<name>.bfrp: it is written when a session that changed the segment ends, or by Export .bfrp below. Exports keep the demo ghost but not your runs.

Variants

A segment with variants always runs one of them: they share the start and the end condition, and each keeps its own loadout, boxes, history and ghosts. Its boxes are under Boxes. The arrows set their order; the game stacks them the same way, the bottom one nearest the card.

Shuffle groups

Each attempt scatters the group's pickups over as many of its locations, chosen fresh.
