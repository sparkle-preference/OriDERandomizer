How this works
A segment is a save file plus rules. In the game, EDIT BOXES on the practice pause freezes the world so you can draw boxes with the mouse: 1 goal, 2 death, 3 hint, Z undo, X delete under the cursor, WASD pans, Enter saves and restarts the attempt. Everything else is edited here and sent back with Save to game: names, hint text, what ends the run, which pickups a shuffle scatters where, and variants, which share the start and the end but bring their own loadout and boxes. To put an item in a box, draw it as a hint box in the game, then set its type to item in the Boxes table and choose what it gives. Pick locations from the zone and location lists or click them on the map; they go to whatever locations go to says. A run ends when every part of the end condition holds at once.
